# Cnchi ![version](https://img.shields.io/badge/version-0.17.0--cnchi--dev-blue.svg) ![License](https://img.shields.io/badge/license-GPL--3.0-blue.svg)

**Graphical installer for Arch Linux** — unmaintained, kept for reference by **Antergos NeXT**.

## Branches

| Branch | Status |
|--------|--------|

## Changes from upstream

- **GTK4 migration** — ported from GTK3 to GTK4
- **GeoIP** — replaced ipstack + 30MB GeoLite2 DB with lightweight ip-api.com
- **Gaming** — Steam, Wine, Lutris, Heroic sub-selection dialog
- **Removed Flash** — end-of-life feature removed entirely
